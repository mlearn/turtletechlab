# turtletechlab

Software test studio setup.

## About Turtle Tech Lab

Turtle Tech Lab is a Sydney-based software studio offering independent software testing and affordable websites for small businesses.

The original website introduced our testing services, approach and contact details.

## V1 updates

- Updated headline highlighting human insight in AI-built software.
- Six service cards covering:
  - Independent Pre-Release Evaluations
  - UAT Support & Coordination
  - Web & Mobile App Testing
  - API & Integration Testing
  - Functional & Exploratory Testing
  - Affordable Websites for Small Businesses
- Dedicated section for affordable business websites.
- Six-step testing process: Submit, Identify Journeys, Review Test Cases, Prepare Automation, Execute and Report.
- Automation included where suitable and agreed.
- Improved hero readability and responsive mobile layout.
- Working mobile navigation and email contact links.
- Updated About section and simplified footer.
- Existing logo and hero artwork retained.
